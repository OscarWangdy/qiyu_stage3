# 棋语 v3｜第三阶段问题探究与风险实证

一套以「漆墨棋局」为主视觉的 16:9 动画网页演示，围绕棋语智能体的事实幻觉、规则逻辑、输出同质化与跨工具对比展开。

## 在线演示

<https://oscarwangdy.github.io/qiyu_stage3/>

## 操作

- `←` / `→`、空格、滚轮或滑动切换页面
- `F` 进入或退出全屏
- `E` 开启页内文字编辑；修改自动保存在本机浏览器

## 实证范围

- 5 个无证据事实请求
- 5 类语言逻辑风险的粗放/精细提示对照
- 5 个非法走法输入与规则层验证
- 同一局面重复运行 3 次
- 棋语语言层与 DeepSeek 原生端点的完全相同用户提示 A/B（两端均为 `deepseek-flash`）

原始逻辑对照、横评记录和内部评分表位于 [`evidence/`](evidence/)。评分采用内部 0–2 记录尺度，不代表官方评分或绝对排名；横评用于观察棋语额外约束层的影响，不是独立基础模型能力排名。
