## 2026-10-10 真实补测

- 幻觉与逻辑各 5 个案例，粗放/精细提示各运行一次，共 20 次模型调用。
- 同质化两组提示各重复 3 次，共 6 次模型调用。
- 棋语、DeepSeek、ChatGPT 各测试 3 题，共 9 份真实回答。每题用户提示逐字相同，保留 SHA-256 校验。
- 另在初始局面重新执行 5 个非法走法，均拒绝。
- 另真实加载冻结v3模型执行初始局面决策，前向钩子记录1次计算，同时搜索深度为0、命中开局库。

当前证据位于 [`evidence/supplement_20261010/`](evidence/supplement_20261010/)。完整检查与限制见 [内容检查报告](第三阶段_内容合理性检查与补测.md)。旧记录保留用于追溯，不再以固定拒答或开局库重复推荐代替生成模型实验。
